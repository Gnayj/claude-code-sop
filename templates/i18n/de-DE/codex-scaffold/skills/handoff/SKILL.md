# Übergabe

Lesen Sie die Quellen immer erneut. Cachen Sie niemals eine Übergabe.

1. Lesen `docs/records/current.md` und identifizieren Sie die Abschnitte „Aktueller Status“ und „Aktive Aufgabe“ anhand
   Überschriften, keine festen Zahlen. Ignorieren archive/closeout Indizes.
2. Aktiv extrahieren `task card:` / `任务卡:` Wege und `design doc:` / `design 文档:` Wege.
3. Lesen Sie nur die goal/scope, Nichtziele, Akzeptanz, Überprüfungsstatus, gesperrte Entscheidungen,
   Grenze der Zusammenarbeit, nächster Schritt und `code-home:` Felder von jedem aktiven Artefakt.
4. Geben Sie den Kollaborationsmodus, aktive Aufgaben, diese Felder, Warnungen für fehlende Artefakte usw. aus
   Nächster Schritt in höchstens etwa 150 Zeilen.
5. Geben Sie dies ausdrücklich an implement/fix erfordert weiterhin ein vollständiges Lesen der aktiven Taskkarte.

Lesen Sie keine Archive, geschlossenen Karten oder nicht verwandten Themendokumente, es sei denn, der Benutzer fragt danach. Niemals schlussfolgern
fehlender Inhalt.
